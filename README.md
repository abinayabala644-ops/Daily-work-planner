# Daily Work Planner

A clean, user-controlled daily scheduling tool designed to plan tasks slot-by-slot from 9:00 AM to 6:00 PM with customizable intervals and end-of-day summary results.

## How to Open
Open `index.html` in any modern web browser, or serve it locally.

## Deploy Online
### Option A: GitHub Pages (Recommended for public repos)
1. Open your repository on GitHub.
2. Go to **Settings** > **Pages**.
3. Under *Branch*, select **main** and set the folder to **/ (root)**.
4. Click **Save**. The live URL will appear within 1–2 minutes.

### Option B: Vercel (Works for public or private repos)
1. Sign in to [Vercel](https://vercel.com) with GitHub.
2. Click **Add New** > **Project** and import `Daily-work-planner`.
3. Set the Root Directory to `./` and deploy without any build command.
